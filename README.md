Chatty – Real-Time Chatting Application

Chatty is a real-time chatting application developed using the MERN Stack. It allows users to communicate through one-to-one and group chats with real-time messaging.

Features
User registration and login
One-to-one real-time chat
Group chat
Online/offline status
Typing indicator
Read receipts
Image and file sharing
User profile management
Chat reminders and notifications
Multiple themes
Auto-delete messages
Mood/emotion-based chat features
Focus mode
Typing speed game and quiz features

Technologies Used
Frontend: React.js, Vite, HTML, CSS, JavaScript
Backend: Node.js, Express.js, Socket.IO

Database: MongoDB, Mongoose
Tools: Git, GitHub, VS Code

Project Objective
The objective of Chatty is to develop a feature-rich real-time communication application and understand the integration of frontend, backend, database, authentication, and real-time communication technologies.

How It Works
Users can register or log in to the application and select another user or a group to start chatting.
The application uses Socket.IO for real-time communication, allowing messages and typing status to be updated instantly without refreshing the page.
The backend manages authentication, messages, groups, reminders, and other application features, while MongoDB stores the application data.
